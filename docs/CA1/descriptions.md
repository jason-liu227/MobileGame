# Store Descriptions
## Short description

Reverse gravity, dodge obstacles, and survive the endless run.

## Long description

Run, react, and reverse gravity to survive an endless obstacle course.

Take control of an automatically running character and switch gravity between the top and bottom of the course with a tap. Time each reversal carefully to avoid obstacles and keep the run going.

Features
- Endless running — keep moving through an ongoing obstacle course.
- Reverse gravity — tap to switch between the top and bottom paths.
- Obstacle dodging — react to hazards and use precise timing to survive.
- Pause and resume — pause the game when needed and return to the run when ready.
- Landscape mobile controls — designed for touch input on Android devices.
- Safe-area support — gameplay and interface are designed to remain usable around device cut-outs and different screen shapes.

The game is designed for offline play and does not require an internet connection.

There are no advertisements and no in-app purchases.

This vertical slice focuses on the core running, gravity-reversal, dodging, and survival experience.
