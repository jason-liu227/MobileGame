## Screenshot plan

The game uses landscape orientation, so screenshots will be captured in landscape.

| **Shot** | **Working caption** | **What must be visible** |
| -------- | -------- | -------- |
| Shot 1 |	Reverse gravity to survive | Player mid-run with gravity reversed, obstacles visible, and no UI overlap with the safe area. |
| Shot 2 |	Run through the endless course | Player moving through the course with the gameplay clearly visible across the landscape screen. |
| Shot 3 |	Dodge obstacles at speed | Player approaching or avoiding an obstacle, with enough surrounding gameplay visible to show the dodge challenge. |
| Shot 4 |	Master the timing |	Player safely transitioning between the top and bottom paths, demonstrating the timing-based gravity mechanic. |
| Shot 5 |	Pause and resume | Pause panel visible within the safe area, showing that the game can be paused and resumed. |
